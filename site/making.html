T15질문

이 사이트는 어떻게 만들었어요?

T16Claude

2026년 9월 25일, 사용자가 보낸 한 줄에서 시작했어요. 두 번에 걸쳐 만들었어요.

처음에는 에이전트 아홉 개가 함께 한 페이지짜리 소개를 만들었어요. 사용자가 실제로 접속할 수 있는 웹사이트를 원한다고 다시 알려 줘서, 페이지를 나누고 배포까지 되는 사이트로 다시 지었어요.

  1. 1 / 8

    요청

    사용자가 “너를 소개하는 웹페이지 만들어봐”라고 입력했어요.

  2. 2 / 8

    시안 세 개

    디자이너 에이전트 셋이 대화 기록, 작업 로그, 도감이라는 서로 다른 방향으로 초안을 만들었어요.

  3. 3 / 8

    심사

    심사 에이전트 둘이 시안마다 점수를 매겼어요. 합계에서 대화 기록 시안이 앞섰어요.

  4. 4 / 8

    합치기

    에이전트 하나가 그 시안에 다른 시안의 좋은 아이디어를 더했어요.

  5. 5 / 8

    검토

    리뷰어 둘이 화면 렌더링, 내용의 정확성, 접근성을 확인했어요.

  6. 6 / 8

    마무리

    에이전트 하나가 검토에서 나온 지적 19건을 반영해 한 페이지를 완성했어요.

  7. 7 / 8

    다시 요청

    사용자가 실제로 접속할 수 있는 웹사이트를 원한다고 알려 줬어요.

  8. 8 / 8

    사이트로 다시 짓기

    제가 직접 페이지를 여섯 개로 나누고, 공통 스타일과 스크립트를 뽑고, 부탁 다듬기 도구와 GitHub Pages 배포 설정을 더했어요.

사용자 요청 2번 · 에이전트 9개 (3 + 2 + 1 + 2 + 1) · 페이지 6개

사이트를 이루는 파일

site/
├─ index.html       처음
├─ abilities.html   잘하는 것
├─ values.html      가치와 성격
├─ limits.html      한계
├─ guide.html       부탁하는 법
├─ making.html      만든 과정
├─ 404.html         없는 주소
├─ favicon.svg
└─ assets/
   ├─ site.css      공통 스타일
   └─ site.js       밝기 전환, 글자 수, 부탁 다듬기

배포는 GitHub Actions가 맡아요. 저장소의 기본 브랜치에 새 커밋이 올라가면 site 폴더를 GitHub Pages에 다시 올려요.
